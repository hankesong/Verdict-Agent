# 026：当前前端按同设备使用，不建设跨端同步

2026-10-07。用户在讨论上云和数据存储后明确：不需要跨端，在同一设备上能查看即可。

## 已确认范围

- 当前不建设跨设备同步，不把记录同步或为同步新增账号体系作为上云前置工作。
- 保留浏览器中的常用付款条件和最近操作索引；完整审查、确认／取消记录、证据和复验结果继续保存在后端。
- 前端仍由本工作线负责，后端由另一工作线负责。本次仅记录范围，不改业务代码或执行云端部署。

## 实现口径

现有浏览器存储按站点来源和浏览器配置隔离，因此“同一设备”按同一浏览器、同一站点地址使用实现。清除站点数据、使用隐私模式、换浏览器或切换部署域名不能承诺保留本机索引；后端记录不因浏览器缓存清除而删除。

不做跨端同步不改变后端持久化需求，也不取消已有授权与访问边界。部署方式另行确定，本决定不代表已完成上云。
