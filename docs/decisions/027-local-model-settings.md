# 027：本地模型设置入口与立即生效接口

2026-10-07。用户要求增加 LLM 设置入口，并明确选择“网页保存后生效，同时补最小后端接口”。本轮授权包含所需的后端和共享协议增量，继续在 STAGING 实施。

## 用户路径

侧栏常驻「模型设置」，路由 `#settings`。执行 Agent 与审查 Agent 分别填写 API 地址、模型名称、OpenAI / GLM 兼容格式和 API Key；高级设置提供超时和输出 Token 上限。显示当前模型及是否配置密钥，不把保存成功称为 API 连通验证。模拟体验不开放真实设置入口。

保存成功后刷新模型与钱包能力，新任务使用新配置；配置和密钥保存在本实例 `dataDir/model-settings.json`，权限为 0600，临时文件写入、fsync、原子改名成功后才更新运行配置。重启按角色加载，优先于原启动配置；原启动配置文件和环境中的凭据不被覆写。网页不使用浏览器存储保存配置或密钥，提交结束和离开设置页清空密钥输入。

## 接口与边界

- `GET /api/settings/models` 返回 `model-settings-v1`、revision 和两类模型的地址、名称、兼容格式、超时、输出上限、来源与 `hasApiKey`。没有密钥值或密钥环境变量名。
- `POST /api/settings/models/agent` / `guard` 接收 `{revision, profile, apiKey?}`；profile 只允许上述五项，保存返回新的完整脱敏快照。
- 省略 apiKey 只在原地址未变化时保留当前密钥；变更地址要求显式提交对应密钥。不调用模型测试连通，不探测其他模型列表，也不产生付费请求。
- 地址只允许 HTTPS 或 loopback HTTP，拒绝认证参数、查询和片段。保留 Host、Origin 和 JSON 请求限制，不增加公共管理接口。启用 defense 的实例继续拒绝旧 API 和此设置入口，OWNER / AGENT / EXECUTOR token 不能通过本入口修改全局模型。
- 正在运行的 PI、钱包审查、许可消费、Guard 报告复验，以及有效待确认／待消费的钱包审查会阻止修改；返回 `MODEL_SETTINGS_BUSY`。旧 revision 返回 `MODEL_SETTINGS_CHANGED`，写盘失败不改变当前配置。
- 模型配置不改变付款授权、RPC、代币范围或确定性核验规则。更换模型／地址后清除旧模型价格估算，防止沿用不适用价格。原测试地址保持 TEST_TRANSPORT 来源，用户换入新地址使用 LIVE；来源不是连接成功声明。
