# 028：钱包前端仅配置审查模型

2026-10-07。用户澄清本次钱包演示由操作者手动发起交易，并明确要求“不要搞执行 AGENT”。本决定收窄 [027](027-local-model-settings.md) 的网页设置范围。

移除模型设置页中的执行 Agent 卡片及编辑入口，仅保留审查 Agent，布局改为单栏。付款仍由用户填写、发起、手写确认并通过钱包签名；不增加付款准备 Agent 或自动执行流程，也不再在页面加入假想执行 Agent 的说明。

既有账户验收的 PI 编排能力属于其他审计工具；本次不删除其后端，也不修改已保存配置。模型设置页只向 `/api/settings/models/guard` 提交，保存审查设置不改动原有 PI 模型配置。
