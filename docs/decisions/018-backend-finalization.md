## 定稿范围

以 `hankesong/Verdict-Agent` 的 `main` 提交 `d972d947a318cebca309e279de31aa0a0bc39254` 为收尾基线，包含已合入的 PR #10 与 PR #11。该提交的文件树与已验证 PR #10 提交 `1aa4c4489cba6be6fae480c1063d9e99d386234f` 相同。本决定更新 003 的开发阶段；已有协议、证据底线和模块职责继续适用。

- A：账户状态、区块头／证明、EIP-712 签名与调用方可信条件核验；证据构造及独立 CLI 重算。
- B：实际签名演示服务、观测与候选排序、有界替换／停止、SQLite 原子采用、下载／导入与第二实例复验，发布状态独立保存。
- PI 与 Guard：直接任务入口、受限业务工具、独立外审与确定性范围拦截、一次性许可、签名安全报告、规则维护和 telemetry 适配。
- 观测与接力：已有只读活动图、外审监控台、威胁账本和 Pi Observability 接口。
- 已合入的钱包后端：签名前审查、许可、BOT 测试网交易回报／receipt／后状态观察及私有观察包重验；这些 RPC 观察与 A 的密码学验收分开。

此次最终 PR 仅整理范围、协作规则、已验证状态和剩余限制。其他工作树的未提交材料分拣、数据集、钱包或存证工作保留原状，不自动收进此次交付，也不据此宣称其完成。

## 本轮不实施

- 不接入 Agent Admission Assessment，不另建 OSV／依赖供应链准入流水线、准入执行器或证据格式。
- 不新增逐动作准入模型审查，不恢复默认草案确认流程。
- 不因历史 PRD、候选建议或接力清单继续扩大后端范围。后续默认是现有范围的缺陷修复、回归验证和交接；功能扩展以用户后续明确要求为准。

## 保留的限制

- 定稿是本轮范围收口，不是生产安全认证；公众多租户认证、分布式执行和生产部署尚不具备。
- 显式 `constraints` 的范围检查已落地；省略时仍依赖独立模型提取授权边界。固定流程和历史草案接口不受新 Guard 外审保护，不宣称全面防提示注入。
- 演示服务的签名属于本地适配器，故障为签名前注入，不代表真实 RPC 厂商事故。账户证据仍依赖调用方接受的检查点与密钥配置。
- A 证据的真实链上存证适配／合约在本基线未接入，默认 `not_requested`；钱包 receipt 成功和 RPC 观察不等于 A 的 PASS、存证成功或主网部署。
- 网页与演示材料可继续围绕已定接口交接；钱包／BOT 观察范围见 [24 号实现说明](../24-钱包活动图与BOT测试网观察.md)。
